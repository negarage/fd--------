# Анастасия Ленская — сайт художницы

Полноэкранное портфолио на Next.js 16.3.0 и React 19. Пять слайдов, светлая и тёмная темы, адаптация для телефонов и планшетов, галерея с детальными карточками и локально сохраняемыми лайками. Связь — через Telegram.

## Локальный запуск

```sh
npm ci
npm run dev
```

Сайт: http://localhost:3000

## Проверка и сборка

```sh
npx tsc --noEmit
npm run build
```

Production-сборка создаётся в `.next/`. Запуск: `npm start`. Сервер слушает `0.0.0.0` и порт из переменной `PORT` (по умолчанию 3000).

Ветка переносит локальный концепт вместо прежней многостраничной версии. Конфиги и lock-файл восстановлены без изменений из исходного коммита `c689743`, до переноса вёрстки. Скриншоты, временные файлы и зависимости не включены.

Контейнерный хостинг должен выполнять `npm ci`, `npm run build`, затем `npm start`. Статический экспорт отключён для совместимости с серверным запуском Next.js. Имеющийся workflow GitHub Pages для Jekyll не используется для запуска Node.js-контейнера.
