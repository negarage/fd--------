# Анастасия Ленская — сайт художницы

Полноэкранное портфолио на Next.js 15 и React 19. Пять слайдов, светлая и тёмная темы, адаптация для телефонов и планшетов, галерея с детальными карточками и локально сохраняемыми лайками. Связь — через Telegram.

## Локальный запуск

```sh
npm ci
npm run dev
```

Сайт: http://localhost:3100

## Проверка и сборка

```sh
npm run typecheck
npm run build
```

Статический сайт собирается в `out/`. Dev-сборка хранится отдельно в `.next-dev/`.

Ветка переносит локальный концепт вместо прежней многостраничной версии. Используются версии зависимостей проверенного локального проекта. Скриншоты, временные файлы и зависимости не включены.

Имеющийся workflow GitHub Pages предназначен для Jekyll; для публикации этого Next.js-сайта его потребуется заменить процессом загрузки `out/`. Эта ветка не меняет публикацию в main.
