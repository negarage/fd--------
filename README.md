# Анастасия Ленская — сайт художницы

Полноэкранное портфолио на Next.js 15 и React 19. Пять слайдов, светлая и тёмная темы, адаптация для телефонов и планшетов, галерея с детальными карточками и локально сохраняемыми лайками. Связь — через Telegram.

## Локальный запуск

```sh
npm ci
npm run dev
```

Сайт: http://localhost:3100

## Проверка и сборка

```sh
npm run typecheck
npm run build
```

Production-сборка создаётся в `.next/`. Запуск: `npm start`. Сервер слушает `0.0.0.0` и порт из переменной `PORT` (по умолчанию 3000). Dev-сборка хранится отдельно в `.next-dev/`.

Ветка переносит локальный концепт вместо прежней многостраничной версии. Используются версии зависимостей проверенного локального проекта. Скриншоты, временные файлы и зависимости не включены.

Контейнерный хостинг должен выполнять `npm ci`, `npm run build`, затем `npm start`. Статический экспорт отключён для совместимости с серверным запуском Next.js. Имеющийся workflow GitHub Pages для Jekyll не используется для запуска Node.js-контейнера.
